# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use
GitHub's private vulnerability reporting for this repository and include the
affected version, reproduction steps, impact, and any proposed mitigation.

Mesh-quality problems, unsupported airfoil inputs, and numerical failures that
do not create a security risk belong in the public issue tracker.

Only the latest release receives security fixes. Users should validate every
generated mesh in their CFD preprocessing workflow before production use.
